# CS4013
To start out project you will have to go to the Run Class and hit the green arrow at the top right.
You will know the project is ready to take your input and and will have a line reading "PCSV Loaded" followed by asking if your an Employee, Admin, Human Resources
or if you want to  quit. 
Employee: if you insert an input "e" you will be taken to the options for and employee.
You'll be asked to insert an ID (for our input use 1111). Once you login it will print your name and ID. Then you can insert "e" to view your details, "v" to see your histoical payslips or "s" to submit a payclaim. For the view payslip you will may to enter a date to check for a paysip of that date. 

Admin:If you selected "a" you wil be asked to insert a password (use admin123). Once the password is correctly entered you will be given 2 options, one to "a" add an employee and "r" remove an employee. Add employee will run you thought a bunch of questions which you will input data into for example employeeID,name,position etc.
Remove employee asks for a employees ID and if the employee exsists it removes them from the system.

Human Resources:If you put in "h" for human resources you will be given a prompt to give an employee a "P" promotion or "G" give a raise to a part time employee.
If "P" is chosen you enter the employees ID and if the employee is found you enter a new position for them. If this position exsists the employee will now have a new position.
If "G" is chosen then you're asked to give a part time employees Id. If This employee exsists it will then ask you to enter a new payrate for them.Once your input is in it will change their pay rate to the new payrate set.
